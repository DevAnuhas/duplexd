# Provider contract harness

Issue [#60](https://github.com/DevAnuhas/duplexd/issues/60) owns a bounded,
synthetic harness for validating Pipecat Cloud session lifetime and cleanup.

The harness is offline-only until a separate operator authorization permits a
real-provider exercise. It must not contain provider credentials, tenant data,
phone numbers, recordings, or production endpoints.

Implementation and operator instructions will live in this directory. The
evidence runbook will distinguish provider documentation, synthetic results,
and live observations.
